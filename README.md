# Elyor Teacher — Ta'limiy Platforma

Professional, zamonaviy va bepul ta'lim platformasi:
1. **Kompyuter savodxonligi** (Kompyuter asoslari, CPU, RAM, SSD, Windows, internet, xavfsizlik, tezkor tugmalar)
2. **Zamonaviy prompt yozish** (AI vositalari uchun samarali promptlar tuzilmasi, rollar, vazifalar, kontekst, amaliy misollar)

Ushbu loyiha faqat **HTML5**, **CSS3** va **Vanilla JavaScript** yordamida yaratilgan.
Hech qanday tashqi API (Gemini, OpenAI), backend yoki ma'lumotlar bazasi talab qilinmaydi. 100% statik va tez ishlaydi.

---

## 🌟 Asosiy imkoniyatlar

- 💻 **2 ta to'liq kurs**: 31 ta bosqichma-bosqich amaliy dars
- ✨ **Haqiqiy prompt misollari**: Dasturlash, dizayn, rasm, video va veb-saytlar uchun tayyor nusxalanadigan promptlar
- 📋 **Bir bosishda nusxalash**: Har bir prompt yonida "Nusxa olish" tugmasi
- 🧠 **Interaktiv testlar (Quizzes)**: Har ikki kurs bo'yicha to'liq testlar, to'g'ri/noto'g'ri javoblar va izohlar
- 📊 **Progress kuzatuvchi**: Darslarni yakunlash va progressni foizda ko'rsatish (brauzer `localStorage` da saqlanadi)
- 🔍 **Tezkor qidiruv**: Barcha darslar va promptlar bo'yicha tezkor kalit so'zlar orqali qidiruv
- 🌐 **3 ta til**: O'zbekcha (UZ), English (EN), Русский (RU)
- 🌓 **Qorong'i / Yorug' rejim (Dark / Light mode)**: Ko'zni charchatmaydigan zamonaviy dizayn
- 📱 **100% Moslashuvchan (Responsive)**: Telefon, planshet va kompyuterlarda qulay ishlaydi

## 🚀 Ishga tushirish (Local)

Loyiha hech qanday o'rnatish talab qilmaydi. Oddiy brauzerda ochish kifoya:

1. Ushbu repozitoriyani yuklab oling yoki klonlang:
   ```bash
   git clone https://github.com/your-username/elyor-teacher.git
   ```
2. Loyiha papkasiga kiring:
   ```bash
   cd elyor-teacher
   ```
3. `index.html` faylini istalgan brauzerda oching (Google Chrome, Firefox, Safari, Edge).

Yoki VS Code ning **Live Server** kengaytmasi yordamida `index.html` ustiga o'ng tugmani bosib "Open with Live Server" ni tanlang.

## 🌐 Vercel yoki GitHub Pages'ga joylash

### GitHub Pages:
1. Loyihani GitHub repozitoriyangizga push qiling (`git push origin main`).
2. Repozitoriya sozlamalariga kiring (`Settings` > `Pages`).
3. Manba sifatida `main` branch va `/root` papkasini tanlang va `Save` tugmasini bosing.
4. Bir necha soniyada saytingiz `https://your-username.github.io/elyor-teacher` manzilida ishga tushadi!

### Vercel:
1. [Vercel](https://vercel.com) saytiga kiring.
2. "Add New Project" tugmasini bosing va GitHub repozitoriyangizni import qiling.
3. Build & Output sozlamalarini o'zgartirish shart emas (Framework Preset: "Other").
4. "Deploy" tugmasini bosing.
